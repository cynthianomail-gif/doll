# 設計筆記與決策紀錄

最後更新：2026-10-19

## 1. 概念演變

1. **最初概念：自創娃娃＋盲盒系列＋開箱演出。** 玩家從材料做娃娃，組成 6+1 款盲盒系列，最後有開箱演出。
2. **縮小範圍：只做娃娃。** 盲盒和開箱暫時拿掉，先驗證「捏娃娃」本身好不好玩。
3. **（旁支點子）「跟女友約會」**：短篇喜劇小遊戲。評估後暫不做，主要風險是容易被解讀成性別刻板印象。
4. **目前方向：接單手作模擬（類似《Dressmaker》）。**
   - 客人上門提出需求 → 玩家自己解讀 → 每一步都是小遊戲 → 交件評價。
   - 娃娃材質可以軟、可以硬，由玩家決定（目前原型只做軟材質布偶）。

## 2. 開發前提

- 作者是遊戲企劃，**不會寫程式也不會畫畫，全部靠 AI 製作**。
- 第一版用網頁技術（HTML5）快速驗證。
- 選 **2D（加假 3D 光影）** 而不是 3D：上色、手繪、裁布在 2D 容易很多，手機效能也比較好。代價是看不到背面、不能轉動。

## 3. 已做的設計決定

| 決定 | 原因 |
|---|---|
| 每一步都是小遊戲（像《Dressmaker》） | 作者選擇；真實的手作手感是賣點 |
| **製作時不顯示「符不符合客人需求」** | 玩家要用自己的理解去設計娃娃；交件後才揭曉客人在意什麼 |
| 內部用「標籤」計分 | 系統看不懂美感，只能比對標籤：版型、布料、顏色、配件都帶有隱藏標籤 |
| 布料依長度計價，要排版 | 讓預算有意義；排版省布是有趣的拼圖 |
| 娃娃拆成部位，每個部位可選造型和布料 | 只有前後片的話沒什麼好剪；混搭布料是創作重點 |
| 對稱的布片用對折、折兩次一起剪（×2、×4） | 布片變多但不重複勞動 |
| 部件要能移動（v0.4 進行中） | 作者要求；採「黏著身體邊緣滑動」的半開放做法，保證做得出來 |
| 衣服依「身形」互穿 | 參考棉花娃娃的實際規則：尺寸 × 體型，例如 20cm 正常體、20cm 胖胖體 |
| 身體比例用滑桿自由調整，身形由數值自動判定 | 作者要求自由度越高越好。滑桿是連續的，但「身高」「胖瘦」會自動歸類成 15/20/25cm × 正常體/胖胖體，衣服互穿的規則仍然成立 |

## 4. 原型目前的遊戲流程（v0.3）

1. **接單**：5 位客人，各有需求原話、預算、柔軟度偏好。
2. **設計**：選身體造型（6 種）、耳朵（6 種）、手（4 種）、腳（3 種）、肚子（3 種）；每個部位可選布料（不織布、印花棉布、毛線針織、短絨毛）和顏色（8 種）。
3. **排版**：每種布是一捲，把布片拖到布上。注意布紋方向、避開污漬，用布越短越便宜。
4. **裁布**：沿虛線剪下每一組布片。
5. **車縫**：先放珠針固定；車縫時要按空白鍵拔珠針；開頭和結尾要按 B 回針；轉角和夾著部件的地方要放慢。
6. **塞棉花**：從棉花袋拉出棉花（按越久越大團）。耳朵、手只能塞小團，而且要在身體塞滿之前先塞。來回揉可以揉平凹凸。最後縫合開口。
7. **裝飾**：17 種配件（眼睛、嘴巴、腮紅、蝴蝶結、補丁、圍巾等），可以自由擺放、縮放、旋轉。
8. **交件**：星數評價、客人評語、收入與聲望，揭曉客人在意的點；可以存成圖片。

## 6. v0.4 的做法（已實作）

- **娃娃由「主體」組成**：動物布偶只有一個身體；人形娃娃有「頭」和「身體素體」兩個主體，各自要車縫、塞棉花，最後縫合頭和身體。
- **人形素體**：一片式的薑餅人形狀（軀幹＋手腳），手腳是可以分開塞棉花的部位。
- **頭型**：圓頭、包子頭、蛋形頭、方圓頭。
- **比例滑桿**：
  - 動物身體：寬度、高度、方圓、上寬↔下寬（疊加在基本形上）。
  - 人形的頭：頭的大小、寬度、高度、方圓。
  - 人形素體：胖瘦、身高、手長、手粗、手的角度、腿長、腿粗、腿距。
  - 身形判定：身高 <0.9 為 15cm、≤1.15 為 20cm、以上為 25cm；胖瘦 ≤1.15 為正常體、以上為胖胖體。
  - 部分極端比例會影響隱藏標籤（例如大頭 → 可愛、很胖 → 療癒）。
- **頭髮**：短髮、齊瀏海長髮、炸毛、雙馬尾、中分；分成瀏海、後髮、馬尾等布片，也要排版和裁剪。
- **屬性耳**：人形娃娃也可以加動物耳朵（例如貓耳），長在頭上。
- **可移動部件**：在設計畫面直接拖曳。部件沿主體輪廓滑動，記錄角度和陷入深度；對稱模式預設開啟；另有大小、角度、重設按鈕。

## 7. v0.5 衣服系統的做法

- **身形**：15/20/25cm × 正常體/胖胖體，共 6 種。娃娃的身形由比例滑桿自動判定。
- **衣服的形狀**：版型的寬度和高度依「衣服的身形」決定；袖子、褲管的角度和長度跟著穿的娃娃走。所以尺寸做錯時，畫面上會直接看到身體從衣服旁邊露出來。
- **衣服種類與滑桿**：上衣（袖長、衣長、寬鬆）、褲子（褲長、寬鬆）、裙子（裙長、蓬度）、斗篷（長度、寬度）。
- **製作流程**：設計 → 排版 → 裁布 → 車縫（衣服外緣，下襬留開口）→ 裝飾（蕾絲、鈕扣、口袋、蝴蝶結等）。
- **衣服訂單**：客人帶自己的娃娃來，原話裡會說娃娃的身形。尺寸做錯直接 1 星「穿不下」。也有「不要裙子」這類限制。
- **自由創作**：不接單，自己出材料費做娃娃或衣服，完成後收進展示櫃、衣櫃。
- **衣櫃**：6 個空白人台＋自己做的娃娃；點衣服穿上或脫下，每個部位（上衣、下身、外套）各一件；身形不同會顯示「穿不下」。

## 8. 已知問題與待決定

- 內部標籤在部件變多後會偏向「可愛」，需要重新平衡。
- 車縫速度、塞棉花速度等手感數值都還沒有真人試玩過。
- 2D 正面圖看不到背面（衣服背面、後腦勺），之後可能需要「轉身」視角。
- 骨架和擺姿勢：真實棉花娃娃有，2D 很難表現，暫不做。
- 硬材質的製作小遊戲（塑形、打磨、上色）還沒有設計。
- 褲子的褲管形狀還很粗糙（像星形），之後要改成真正的褲管版型。
- 衣服只有正面；動物布偶還不能穿衣服。
- 衣櫃和收藏只存在瀏覽器分頁裡，重新整理就會消失（還沒有存檔）。

## 9. 試玩時要觀察的問題

1. 排版的省布拼圖好不好玩？
2. 車縫一手拿滑鼠、一手按鍵，會不會太忙？
3. 「末端先塞」的規則有趣還是挫折？
4. 拿掉需求提示後，玩家是照自己的理解做，還是覺得像亂猜？
5. 做完一隻之後，會不會想接下一位客人？
